# Archived project files

These files were moved out of the active Django package because they are legacy copies, maintenance scripts, duplicate templates, or runtime logs. They are retained for reference and are not imported by the application.

- `legacy_python/` contains obsolete view and experiment files.
- `maintenance_scripts/` contains one-off repair or data scripts.
- `legacy_templates/` contains the duplicate `templates1` directory.
- `logs/` contains historical runtime logs.
